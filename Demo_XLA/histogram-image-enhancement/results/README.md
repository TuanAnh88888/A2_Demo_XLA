# Thư mục Kết Quả (Results)

Thư mục này dùng để lưu trữ các ảnh kết quả sau khi thực hiện xử lý hoặc xuất báo cáo:

- Ảnh sau Histogram Equalization (`equalized_*.png`)
- Ảnh sau CLAHE (`clahe_*.png`)
- Ảnh sau điều chỉnh Độ sáng (`brightness_*.png`)
- Ảnh sau điều chỉnh Độ tương phản (`contrast_*.png`)
- Biểu đồ so sánh và bảng số liệu định lượng phục vụ báo cáo khoa học và thuyết trình.

Người dùng có thể tải trực tiếp ảnh kết quả thông qua nút **Tải ảnh kết quả** trên giao diện ứng dụng Streamlit.
