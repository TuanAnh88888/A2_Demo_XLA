# DỰ ÁN XỬ LÝ ẢNH SỐ: HISTOGRAM VÀ TĂNG CƯỜNG CHẤT LƯỢNG ẢNH

Thư mục chính của dự án nằm tại: `histogram-image-enhancement/`

## Hướng dẫn khởi chạy nhanh trong Visual Studio Code

```bash
cd histogram-image-enhancement

python -m venv .venv

.venv\Scripts\activate

pip install -r requirements.txt

streamlit run app.py
```
*(Hoặc chạy lệnh: `python -m streamlit run app.py` hoặc nhấp đúp file `run.bat`)*
